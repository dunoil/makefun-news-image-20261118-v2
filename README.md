# The World in One Image — Wednesday 18 November 2026 (v2)

A dense one-page broadsheet of the day's world news, drawn entirely in code.
`main.ts` (Node 22, standard library only, no network) paints the page
pixel by pixel on a 2x supersampled canvas — gradient skies, drawn scenes
for every story, a dot-matrix world map, a 5x7 bitmap typeface, and a
whisper of newsprint grain — and writes a deterministic 1024x1024 PNG to
`/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`).

Run it:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Output: `entry.png`, 1024x1024, 537,659 bytes, SHA-256
`3175d1c3e8c3e63b898acbdb7f406c1745e9d2cc4b439285f3c6213ba8a56ed5`
(identical across repeated runs).
